방법·주의

  • 최초 등장 규칙: 분기 FSR을 시간순으로 읽어 (리그, 용선료) 조합이 처음 나타난 보고서 날짜를 체결 시점으로 본다. 같은 리그·같은 기간에 ±3.5% 이내로 바뀐 값은 에스컬레이션으로 보고 새 계약으로 세지 않음. 연 단계 인상 계약(Songa·Equinor 장기 등)은 첫 단계만 표시.
  • 세대 분류(KT): 8G = Titan·Atlas(20K), 7G = Asgard·Invictus·Thalassa·Proteus·Pontus·Poseidon·Conqueror·Aquila·Skyros·Athena·Mylos·Apollo, 6G = Clear Leader·Americas·Inspiration·India·Luanda·Champion·KG1/2·Petrobras 10000·Corcovado·Mykonos·Orion·Olympia·DD3, 5G이하 = Enterprise급·Deepwater Discovery급·DD I/II 등, HE = 극한환경 반잠수식, 중수심 = Deepwater/Midwater floater, 잭업.
  • 공백: 2014Q3(변경분만 공시), 2016Q4(용선료 미공시), 2023Q1·2026Q4(수주 보도자료만) — 해당 분기 신규 계약은 다음 보고서에 처음 등장. 2016년 SEC HTML은 숫자가 유실돼 회사 PDF로 보완(2016Q4 제외).
  • 오차: 보고서 텍스트를 모델로 전사한 값이라 숫자 오독(예 341↔431)이 섞일 수 있음. 한 보고서에만 보이고 사라진 값은 '미확인'으로 분리.
  • 용선료는 서비스·리임버서블·모빌라이제이션 포함 여부가 보고서마다 달라 ±5~10% 비교 오차. 2011~2015년 표는 $000 단위.
  • 공백 구간: Noble은 2011.7~2021.3 FSR을 SEC에 내지 않고 자사 사이트에만 게시 → 현재 원본을 구할 수 없어 Noble 2011.Q4~2021.Q1은 비어 있음(2011.1~7 3개 보고서, 2021.6~ 보고서만 사용). 공백 직후 보고서에 이미 진행 중이던 계약은 공백기에 체결된 것이라 체결 시점을 알 수 없어 '기존 계약'으로 분리(속 빈 점, 기본 제외). Seadrill은 2013년까지 계약표에 용선료 열이 없어 신규계약 서술분만, 2016.Q3·2017.Q1·2017.Q4~2018.Q1은 직전 보고서로 대체. Noble 2022.Q4는 잭업이 잘린 재게시본이라 플로터만.
  • 총액÷일수 추정값(◇): 용선료 대신 계약총액만 공시된 계약 — Transocean FSR 이후 수주 보도자료, Noble FSR의 'valued at USD xM'(2023~), Seadrill FSR·보도자료의 TCV(2023.12~; 2025.11부터 Seadrill FSR은 용선료 열 자체를 없앰). 계약총액÷일수(일수 미공시 시 시작~종료 개월×30.4)로 KT가 역산. 모빌·추가서비스 포함 총액은 실제 단가보다 높게 나오며 비고에 표시. 역산값이 플로터 $20만 미만·$65만 초과면 기간·모빌 왜곡으로 보고 제외. 체크박스로 끄면 통계·차트에서 빠짐.
  • 통계 제외: 점은 그리되 중앙값·표에서 빼는 값. 설치 기간 임시 단가, 모빌·서비스가 섞인 총액 역산값 등. 사유는 표 비고와 툴팁에 표시.
  • 주간 갱신: 매주 토요일 각사 SEC 8-K·IR 보도자료·선대현황보고서를 수집하고, 새 계약을 같은 규칙으로 CSV에 추가한다.
